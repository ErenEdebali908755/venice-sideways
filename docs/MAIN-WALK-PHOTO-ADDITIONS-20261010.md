# Main Walk · three real photographs per stop

10 October 2026. Ten existing cover files/IDs remain unchanged. Twenty additions use the same explicit gallery relation, attribution and lazy-image renderer. New derivatives: 800 and 1600 pixels wide, WebP, original framing, no retouching; metadata stripped.

Selection: varied general, detail and setting views. Commons file identity/category/description and visual inspection were checked; available coordinates are recorded rather than invented. Dogana additions show only the exterior. No identifiable person or modern artwork is the focal subject. Two initially proposed images were rejected in parent review (foreground gondolier; bridge too small behind palace), then replaced.

The Accademia setting view is photographed from the bridge, with its viewpoint stated in the caption. Commons file coordinates can describe camera or subject; they are corroboration, not a precision claim.
